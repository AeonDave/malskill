# proxychains-ng

Preloads hooks for network-related libc calls and routes compatible applications' TCP connections through SOCKS4a/5 or HTTP proxies. Applications that bypass those calls are not covered.

## Core workflow

```bash
# Explicit config path avoids distribution-specific lookup differences
# List the SOCKS listener under [ProxyList]:
#   socks5  127.0.0.1 1080

# Route a command through the tunnel
proxychains4 -f ./proxychains.conf nmap -sT -Pn -n -p 445 10.10.10.0/24
proxychains4 -f ./proxychains.conf impacket-smbexec domain/user:pass@10.10.10.5
proxychains4 -f ./proxychains.conf curl http://10.10.10.5:8080/admin

# Quiet mode (suppress proxychains banner)
proxychains4 -f ./proxychains.conf -q nmap -sT -Pn -n 10.10.10.0/24

# Chain multiple proxies (strict_chain = all must be alive; dynamic_chain = skips dead)
# Enable exactly one chain mode before [ProxyList]
```

## Best practice

- **Nmap through proxychains**: use `-sT` (full TCP connect) — SYN scan (`-sS`) sends raw packets that bypass the SOCKS layer and leak the operator IP.
- **Chain modes**: both preserve list order. `strict_chain` requires every listed proxy; `dynamic_chain` skips unavailable proxies and needs at least one working proxy. Choose according to which hops are required.
- **`proxy_dns`** handles resolution through supported libc hooks; it does not intercept arbitrary DNS traffic generated by an application.
- **`quiet_mode`** in the config suppresses the banner on every invocation.
- Upstream lookup uses `-f`/`PROXYCHAINS_CONF_FILE`, `./proxychains.conf`, `~/.proxychains/proxychains.conf`, then the build's system config directory. Distribution packages may use another system filename.

## Gotchas

- Static binaries cannot load the hooks. Dynamically linked programs can also fail when they bypass libc networking; do not infer compatibility from language or libc name alone.
- proxychains-ng supports TCP only: neither UDP nor ICMP is proxied, even with a SOCKS5 server.
- Nmap's raw-packet operations are outside the wrapper. `-n` disables Nmap DNS resolution; it does not route that resolution through proxychains.
